This will probably be one of the most interesting sections.

Example:

| AI       | Best at                         | Weakness                             |
| -------- | ------------------------------- | ------------------------------------ |
| ChatGPT  | Architecture, planning, reviews | Doesn't see live UI                  |

# 5. Rules for Future Development

For example:

* Architecture before implementation.
* Never rewrite working code.
* One bug at a time.
* Always isolate root cause first.
* Finish one tool completely before starting another.
* Ship, then optimize.

These become your development rules.
