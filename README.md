# Free JSON Toolkit

> Fast, privacy-first JSON utilities that run entirely in your browser.

Convert, validate, format, and manipulate JSON without uploading your data to any server.

🌐 https://freejsontoolkit.com

---

## Features

### Available

- JSON → CSV Converter
- Drag & Drop file support
- Large file support
- Web Worker processing
- Offline processing
- Copy / Download output
- Mobile responsive
- Accessible interface
- Zero tracking of your data

### Coming Soon

- CSV → JSON
- JSON Formatter
- JSON Validator
- JSON Compare
- JSON Minify
- JSON Beautify
- JSON Schema Viewer
- XML ↔ JSON
- YAML ↔ JSON
- SQL ↔ JSON

---

## Why Free JSON Toolkit?

Most online JSON tools upload your data to a server.

Free JSON Toolkit processes everything locally inside your browser.

Your files never leave your computer.

No accounts.

No API keys.

No subscriptions.

No tracking of your JSON.

## Development

Clone the repository

```bash
git clone https://github.com/pelomehuliyo/freejsontoolkit.com.git
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

Run tests

```bash
npm test
```
